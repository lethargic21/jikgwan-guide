# 가을야구 원정 직관 가이드 — 홈경기의 지역 관광 효과 분석

프로야구 홈경기가 구장 소재 지역의 외지인 방문에 주는 효과를 한국관광 데이터랩 데이터로 측정하고, 그 결과로 9개 구장 원정 직관 가이드 웹을 만든 개인 프로젝트입니다. (2026 한국관광 데이터랩 활용 경진대회 응모작)

- **가이드 웹**: `web/` (GitHub Pages로 배포)
- **핵심 결과** (`outputs/findings.md`)
  - 홈경기날 구장 소재 시군구 외지인 방문 **+7.3%** (95% CI 6.8~7.8%, 9개 구장 2,666 경기일), 경기당 약 1만 700명
  - 경기 전날 +0.01%, 다음날 +0.07% — 늘어난 외지인은 대부분 당일에 떠난다(체류 전환 실패)
  - 기대효과(추정): 원정 관중 숙박 전환 +1%p 시 연 약 41억~72억 원 (산식·가정은 findings.md 26번)

## 재현
```
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt
.venv/Scripts/python analysis/run_all.py
```
- `.env`에 공공데이터포털 인증키 `DATA_GO_KR_KEY`가 필요합니다(지역별 방문자수·TourAPI).
- 데이터랩 수동 다운로드 자료(신용카드 관광지출액, 중심-연관 관광지, 국민여행조사)와 KBO 경기 원자료는 재배포하지 않습니다. 받는 방법은 `docs/datalab_download_list.md`, `data/raw/kbo/SOURCE.md`, `analysis/00_fetch_kbo.py`를 보세요.

## 구조
| 경로 | 내용 |
|---|---|
| `analysis/` | 00 수집·정리 → 02 패널 → 03 경기일 효과 → 05 광역 → 09·10 데이터랩 D1·D2 → 11 기대효과 → 04 그림 → 06·07·08 웹 데이터 |
| `outputs/` | 표(`tables/`), 그림(`figures/`), 핵심 수치(`findings.md`) |
| `web/` | 정적 가이드 웹 (HTML/CSS/JS, 빌드 없음) |

## 데이터 출처
- 한국관광 데이터랩: 빅데이터 › 이동통신 › 지역별 방문자수(공공데이터포털 '한국관광공사_빅데이터_지역별 방문자수' API), 신용카드 › 지역별 관광지출액, 지역별 분석 › 중심-연관 관광지, 국민여행조사
